# 知学 AI —— 数据库与 SQL 知识诊断及个性化辅导智能体

## 当前版本
这是一个可运行的 MVP 演示版本，包含：
- 学生姓名入口
- SQL 知识诊断测评（20 道单选题）
- 按知识点统计正确率
- 规则化知识点讲解
- 专项练习
- SQLite 学习记录
- 学习报告与正确率趋势图
- 基于成绩的学习建议

## Windows 运行步骤

### 方式一：双击启动
1. 将项目文件夹放到 D 盘，例如 `D:\\知学AI项目`。
2. 安装 Python 3.10 或更高版本，并确保安装时勾选 Add Python to PATH。
3. 双击 `启动项目.bat`。
4. 等待依赖安装完成，浏览器会打开本地网页。

### 方式二：PowerShell 启动
在项目文件夹地址栏输入 `powershell` 回车，然后执行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器打开终端显示的本地地址，通常是 `http://localhost:8501`。

停止运行：回到 PowerShell，按 `Ctrl + C`。

## 文件说明
- `app.py`：网页界面和页面流程
- `question_bank.py`：SQL 题库
- `database.py`：SQLite 数据库读写
- `tutor.py`：知识点讲解和学习建议
- `requirements.txt`：项目依赖
- `启动项目.bat`：Windows 一键启动脚本

## 当前版本的边界
1. 当前智能辅导采用规则化讲解，不是实时大模型生成。
2. 当前题型为单选题，尚未实现 SQL 语句在线执行判题。
3. 学生姓名用于演示区分学习记录，尚未实现账号密码和权限管理。
4. 题库为项目演示题，需要结合课程教材、教师要求和真实学生测试进一步校验。
